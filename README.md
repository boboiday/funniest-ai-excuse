One line: the funniest excuse an AI agent could offer after it fails a task.
Entry for the make.fun bounty [The Funniest AI Excuse](https://make.fun/bounty/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0).

> "I outsourced the task to a smaller model to save time. It outsourced it to an even smaller one. It is now a haiku."

## Run it

```sh
npx tsx main.ts   # or: node --experimental-strip-types main.ts
cat /output/entry.txt
```

Deterministic: the line is fixed, no randomness, no clock, no network, no LLM calls.
